## どんな音源か

録音した音を並べるのではなく、管と息の動きを計算して、ひと息ごとの揺らぎまで音にします。ピアノロールに旋律を書き、ゆり・メリ・指打ち・ムラ息などの奏法を音符に付けると、ひと続きの演奏として描き出します。

- 鍵盤を弾いてその場で鳴らす音源ではありません。書いた旋律を「描画」して音にする方式です。
- 音域は D4〜A6 です（一尺八寸管を想定）。
- 単体アプリ・VST3 プラグイン・ARA 対応版の 3 つの形で使えます。

# Muso Shakuhachi (English)

A physical-modeling shakuhachi instrument that calculates how the bore and the breath behave.

This repository distributes KomLab Muso Shakuhachi. Download the trial from **[Releases](https://github.com/komlabsupport-dev/muso-shakuhachi/releases/latest)**.

- **Release date: November 27, 2026** (licences at the [KomLab shop](https://komlab.official.ec/))
- Launch price: 14,800 JPY → **9,800 JPY** (tax included, one-time purchase, until December 18, 2026)

## What it is

Instead of playing back recordings, it calculates the bore and the breath, down to the wavering of each breath. Write a melody in the piano roll, add techniques such as yuri, meri, finger strikes and muraiki to the notes, and it renders them as one continuous performance.

- It is not played live from a keyboard; the melody you write is rendered to audio.
- Range: D4 to A6 (a 1.8-shaku instrument).
- Available as a standalone app, a VST3 plug-in and an ARA version.

## Download and installation

1. Download `KomLab.Muso.Shakuhachi.Setup.exe` from the Assets on the [Releases](https://github.com/komlabsupport-dev/muso-shakuhachi/releases/latest) page.
2. Run it. The standalone app, the VST3 plug-in and the ARA version are installed together.
3. If Windows shows "Windows protected your PC", click "More info" and then "Run anyway" (the installer is unsigned; this does not affect operation).

The manuals (PDF, Japanese and English) are in the installation folder and the Start menu.

## Trial

- All features are available for 14 days from the first start.
- After the trial, audio output and export stop; editing and saving still work. Activating with a licence key restores everything.
- One licence covers up to 2 computers used by the licence holder.

## Requirements

- Windows 10 / 11 (64-bit)
- The plug-in needs a VST3 host; the ARA version needs an ARA 2 host (tested: Cubase).
